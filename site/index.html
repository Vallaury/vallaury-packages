Vallaury per Linux

Repository ufficiali firmati per installare e aggiornare Vallaury con il gestore di pacchetti della tua distribuzione.

Ubuntu, Debian e derivate

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://sappafrancesco.github.io/vallaury-packages/vallaury.gpg | sudo tee /etc/apt/keyrings/vallaury.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/vallaury.gpg] https://sappafrancesco.github.io/vallaury-packages/apt stable main" | sudo tee /etc/apt/sources.list.d/vallaury.list
sudo apt update
sudo apt install vallaury-desktop

Fedora, RHEL e derivate

sudo curl -fsSL -o /etc/yum.repos.d/vallaury.repo https://sappafrancesco.github.io/vallaury-packages/vallaury.repo
sudo dnf install vallaury-desktop

openSUSE

sudo zypper addrepo https://sappafrancesco.github.io/vallaury-packages/vallaury.repo
sudo zypper install vallaury-desktop

Architetture: x86_64 (amd64) e aarch64 (arm64). Chiave di firma: vallaury.asc, impronta E1B5 5711 9138 0C27 C8C9 8381 C9D6 EB50 B55A 78C5.

Codice sorgente dell'app: sappafrancesco/vallaury-desktop (GPL-3.0-only).
